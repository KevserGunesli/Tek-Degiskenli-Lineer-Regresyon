# Tek Değişkenli Lineer Regresyon

Bu proje, tek değişkenli lineer regresyon algoritmasının temel prensiplerini ve uygulamasını içermektedir. Analizler ve görselleştirmeler `projeson.ipynb` dosyasında Jupyter Notebook formatında sunulmuştur.

## İçerik

- Veri setinin tanıtımı
- Verilerin görselleştirilmesi
- Lineer regresyon modeli oluşturulması
- Modelin eğitilmesi ve değerlendirilmesi
- Sonuçların yorumlanması

## Kullanım

1. `projeson.ipynb` dosyasını Jupyter Notebook veya Google Colab ile açın.
2. Gerekli kütüphaneleri yükleyin.
3. Hücreleri sırayla çalıştırarak analizleri takip edin.

## Gereksinimler

- Python 3.x
- NumPy
- pandas
- matplotlib
